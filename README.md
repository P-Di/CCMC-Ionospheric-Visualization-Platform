# CCMC-Ionospheric-Visualization-Platform

Dash application for browsing CCMC ionosphere, thermosphere, and GNSS validation projects.

## Setup

Install the project dependencies from the pinned requirements file:

```bash
pip install -r requirements.txt
```

Start the app with:

```bash
python app.py
```

## Requirements

Primary runtime packages include `dash`, `dash-bootstrap-components`, `plotly`, `numpy`, and `pandas`.

The full pinned dependency list is maintained in [requirements.txt](requirements.txt).
